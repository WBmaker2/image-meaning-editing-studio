# 튜토리얼 중앙 이미지 개선 계획

## 요청

시작 전 안내의 세 카드 중앙에 있는 기호 픽토그램을 학습 맥락에 맞는 이미지로 교체한다.

## 선택한 이미지

- 약속 01 `처음 이미지도 골라 보여 준 장면이에요` → 운동장 벤치 생성 이미지
- 약속 02 `한 번에 하나씩 바꾸어 봐요` → 복도 걷기 안내판 생성 이미지
- 약속 03 `보이는 것과 느낌을 구분해요` → 학교 텃밭 새싹 생성 이미지

이미 앱에서 사용 중인 생성 이미지라서 별도 이미지 생성 없이 동일한 장면 자산을 재사용한다. 이렇게 하면 튜토리얼과 사건 활동에서 같은 사물·색·그림을 다시 만나 학습 연결이 쉬워진다.

## 구현 원칙

- 기존 기호 문자는 제거하고 실제 `<img>` 요소와 장면별 대체 설명을 사용한다.
- 카드 중앙의 둥근 프레임은 유지하되 이미지가 잘리지 않도록 `object-fit: cover`와 장면별 위치를 적용한다.
- 이미지가 늦게 로드되거나 실패해도 카드 높이가 흔들리지 않도록 배경색과 고정 프레임을 유지한다.
- 업데이트 내역에 이번 변경을 기록한다.

## 완료 기준

- 세 카드 중앙에 아이콘 대신 생성 이미지가 보인다.
- 이미지 대체 설명이 학습 장면을 설명한다.
- 모바일 화면에서 이미지와 카드 내용이 겹치지 않는다.
- 타입 검사, 린트, 테스트, Pages 빌드와 공개 URL에서 이미지 로드를 확인한다.

## 구현·검증 결과

- 세 카드 중앙의 픽토그램을 `rain-bench.png`, `hallway-sign.png`, `garden-caption.png` 생성 이미지로 교체했다.
- 장면별 대체 설명과 이미지 위치를 추가하고, 모바일에서는 이미지 프레임을 130px로 줄여 카드 내용과 겹치지 않게 했다.
- 업데이트 내역 `v0.8.0`에 변경 내용을 기록했다.
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build:pages`를 통과했다.
