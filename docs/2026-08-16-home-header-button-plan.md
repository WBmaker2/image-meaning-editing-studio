# 상단 홈 화면 버튼 개선 계획

## 요청

사건 보관함이나 학습 화면에서 첫 화면으로 바로 돌아갈 수 있도록 상단 헤더에 `홈 화면` 버튼을 추가한다.

## 구현 원칙

- 기존 브랜드 버튼과 같은 동작을 사용해 홈 화면 이동 규칙을 한 곳으로 유지한다.
- 교사용 안내·업데이트 내역과 같은 헤더 도움말 영역에 배치해 어느 화면에서도 찾기 쉽게 한다.
- 모바일에서도 글자가 잘리지 않도록 기존 헤더 액션의 반응형 규칙을 확인한다.
- 업데이트 내역에 이번 변경을 기록한다.

## 완료 기준

- 헤더에 `홈 화면`이라는 이름의 버튼이 보인다.
- 버튼을 누르면 첫 화면으로 이동하고, 이전 학습 화면의 상태가 남지 않는다.
- 데스크톱과 모바일에서 헤더가 넘치지 않는다.
- 타입 검사, 린트, 테스트, Pages 빌드와 공개 URL에서 동작을 확인한다.

## 구현·검증 결과

- 상단 `사이트 메뉴`에 `홈 화면` 버튼을 추가하고 브랜드 버튼과 같은 첫 화면 이동 동작을 연결했다.
- 모바일에서는 `교사용 안내`를 접고 `홈 화면`과 `업데이트 내역`을 계속 보여 주도록 했다.
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build:pages`를 통과했다.
