# CSS 그림을 생성 이미지로 교체하기

## 목표

홈 소개 화면과 사건 보관함 카드에 남아 있는 CSS 도형 그림을 기존 생성 학습 이미지로 교체한다. 사건을 연 뒤 사용하는 큰 비교 화면의 이미지와 같은 자산을 사용해 화면 사이의 장면이 일관되게 보이도록 한다.

## 확인 결과

- `SceneIllustration`의 큰 비교 화면에는 이미 생성 이미지 5개가 연결되어 있다.
- 홈의 `hero-lab` 안 `mini-scene`은 CSS 도형으로 벤치·우산·해를 그린다.
- 사건 카드의 `thumb-illustration`은 CSS 도형으로 장면을 요약한다.
- 기존 생성 이미지 5개가 각 사건의 맥락과 정확히 대응하므로 추가 이미지 생성은 필요하지 않다.

## 교체 매핑

| 화면 | 기존 CSS 그림 | 사용할 생성 이미지 |
| --- | --- | --- |
| 홈 넓은 예시 | 벤치·우산·해 도형 | `rain-bench.png` |
| 홈 가까운 예시 | 확대 벤치 도형 | `rain-bench.png`의 가까운 자르기 |
| 사건 1 카드 | CSS 벤치·우산 | `rain-bench.png` |
| 사건 2 카드 | CSS 안내판 도형 | `hallway-sign.png` |
| 사건 3 카드 | CSS 새싹 도형 | `garden-caption.png` |
| 사건 4 카드 | CSS 준비물 도형 | `supply-sign.png` |
| 사건 5 카드 | CSS 나눔함 도형 | `share-box.png` |

## 구현 순서

1. 장면 자산 매핑을 공통 모듈로 분리해 홈·카드·비교 화면이 같은 경로를 사용한다.
2. 홈 소개 이미지와 사건 카드 썸네일을 `<img>` 기반으로 교체하고 모바일 자르기를 조정한다.
3. 사용하지 않는 CSS 도형 스타일을 제거하고, 이미지가 보이도록 필요한 레이아웃 스타일만 남긴다.
4. 타입 검사, 린트, 테스트, Pages 빌드와 브라우저에서 홈·카드·비교 화면을 검증한다.
5. 업데이트 내역에 이번 교체 내용을 기록한다.

## 완료 기준

- 홈 소개 영역에 생성 이미지가 보인다.
- 5개 사건 카드에 각각 대응하는 생성 이미지가 보인다.
- 사건을 연 뒤의 비교 이미지와 자산이 일치한다.
- CSS 도형으로 장면을 그리던 시각 요소가 남아 있지 않다.
- 모바일 화면에서도 이미지가 잘리지 않고 카드 제목·버튼과 함께 읽힌다.
