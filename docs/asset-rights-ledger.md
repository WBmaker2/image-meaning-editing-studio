## 생성 이미지 사용 원칙

- 모든 장면은 `public/learning-scenes/`에 고정 자산으로 저장합니다.
- 같은 장면 자산을 홈 소개 이미지, 사건 카드 썸네일, 사건 비교 화면에서 재사용합니다.
- 실제 학생·교사·얼굴·손·학교명·상표를 포함하지 않습니다.
- 생성 이미지에는 학습 판정에 필요한 한국어 문장을 넣지 않고, 앱 HTML 오버레이가 정확한 글자를 보여 줍니다.
- 장면의 자르기·크기·색 변화는 기존 학습 프리셋이 결정적으로 적용합니다.
- 생성 프롬프트와 관찰 목표는 `docs/2026-08-15-generated-learning-images-plan.md`에 기록합니다.
