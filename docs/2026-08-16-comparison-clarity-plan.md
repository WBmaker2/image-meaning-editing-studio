# 비교 화면 차이 인식 개선 계획

## 요청

초등학생이 처음 이미지와 바꾼 이미지를 나란히 보았을 때 무엇이 달라졌는지 바로 찾지 못하는 문제를 조사하고, 비슷한 문제가 있는 모든 학습 사건의 비교 화면을 개선한다.

## 점검 결과

- **1번 자르기**: 확대 비율은 바뀌지만, 작은 화면에서는 주변이 얼마나 잘렸는지 한눈에 찾기 어렵다.
- **2번 크기·자리**: 안내 글 위치와 크기가 바뀌지만, 이미지 위에 겹친 글의 강조가 약하다.
- **3번 글**: 사진은 같고 캡션만 바뀌는 활동이라서, 사진이 같다는 사실과 글 변화가 더 분명히 안내되어야 한다.
- **4번 색·밝기**: 필터 수치가 약해 원래 색과 옅은 색의 차이가 작게 보일 수 있다. 원래 색 선택은 기준 이미지와 같은 상태라는 설명도 필요하다.
- **5번 여러 가지**: 현재 변형은 작은 확대·색 필터 중심이라서, “물건을 크게”, “참여를 따뜻하게”, “이름표를 먼저”라는 설명과 화면 차이가 잘 맞지 않는다. 첨부 화면의 핵심 문제다.

## 개선 원칙

1. 각 선택지는 1280px와 모바일 폭 모두에서 적어도 하나의 큰 변화(자르기, 위치, 글 크기, 색 대비)를 보여 준다.
2. 화면의 변화와 설명 문장을 일치시킨다. 필터만으로 의미를 설명하지 않고, 학생이 볼 수 있는 글·테두리·색 띠·크기 차이를 함께 사용한다.
3. 오른쪽 카드 상단에 짧은 “어디를 볼까요?” 안내를 표시해 학생이 찾아야 할 시각 단서를 알려 준다.
4. 사진 자체가 같은 3번과 원래 색인 4번은 “사진/색은 그대로”라고 명시해, 차이가 없는 것이 오류가 아님을 알려 준다.
5. 기존 생성 이미지를 재사용한다. 현재 학습 맥락에 맞는 5개 생성 이미지가 이미 있으므로 새 이미지는 만들지 않는다.

## 구현 순서

1. 선택지별 시각 단서 문구를 데이터로 추가하고 비교 카드에 표시한다.
2. 약한 변형(특히 나눔함, 색·밝기, 안내판)에 명확한 크기·자리·색 대비 스타일을 추가한다.
3. 4번 원래 색의 설명을 기준 이미지와 동일하다고 명확히 고친다.
4. 업데이트 내역에 이번 개선을 기록한다.
5. 타입 검사, 린트, 테스트, Pages 빌드와 실제 공개 URL의 모든 사건·선택지 비교 화면을 확인한다.

## 완료 기준

- 각 사건의 선택지를 바꿀 때 오른쪽 카드에 선택지별 안내 단서가 보인다.
- 나눔함 선택지 3개는 이미지의 크기·색·글 위치 중 하나 이상이 분명히 달라진다.
- 색·밝기 선택지의 원래 색, 옅은 색, 강한 대비, 낮은 대비가 서로 구분된다.
- 학생용 문장은 짧고 “무엇을 볼지”를 직접 알려 준다.
- 공개 Pages에서 이미지 로드 오류나 콘솔 오류가 없다.

## 구현·검증 결과

- 선택지별 시각 단서 문구를 비교 카드 오른쪽 상단에 표시했다.
- 안내판은 글의 크기·자리·강조 띠를, 준비물은 색·대비·이름표 테두리를, 나눔함은 확대·축소·따뜻한 색 띠·이름표 크기를 강화했다.
- 텃밭 글과 준비물 원래 색처럼 사진·색이 그대로인 선택지는 “그대로” 또는 “글만 바꿔요”라고 안내한다.
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build:pages`를 통과했다.
- 공개 URL에서 5개 사건의 모든 선택지를 순서대로 확인했으며 콘솔·요청 오류 0건, 생성 이미지 5개 모두 `naturalWidth > 0`을 확인했다.
