# 이미지 의미 편집실 기능·UI 개선 기록

- 점검일: 2026-07-17
- 점검 범위: 첫 화면, 시작 안내, 사건 선택, 관찰, 편집, 분석, 결과 기록, 모바일 반응형
- 점검 환경: 로컬 빌드, 1280×720 / 768×1024 / 375×812

## 기준 화면 평가

현재 앱은 따뜻한 종이 질감, 청록·호박색 중심의 색 체계, 일관된 카드와 버튼을 사용해 교육용 작업실이라는 인상이 분명합니다. 실제 사진을 업로드하지 않고 미리 만든 장면을 비교하게 한 점도 개인정보 보호와 수업 운영 측면에서 적절합니다.

다만 학습 목표인 “보이는 변화와 가능한 느낌을 화면 근거로 구분하기”가 일부 단계에서 충분히 강제되지 않았습니다. 아래 항목을 우선 개선합니다.

## 발견한 개선점과 구현 계획

| ID | 우선순위 | 영역 | 발견 내용 | 개선 계획 |
|---|---|---|---|---|
| F-01 | 높음 | 학습 기능 | 관찰 목록이 이미 모두 `보여요`로 표시되어 학생이 실제로 확인하지 않아도 다음 단계로 갈 수 있음 | 각 단서를 직접 체크하게 하고 완료 수를 표시하며, 전부 확인하기 전에는 편집 단계로 이동하지 못하게 함 |
| F-02 | 높음 | 답 판정 | 정답 범위가 `추측 가능`인 경우에도 `직접 확인`을 선택하면 통과하는 예외가 있어 사실과 느낌의 구분이 흐려짐 | 기대 범위와 선택 범위를 엄격하게 일치시키고 회귀 테스트를 추가함 |
| F-03 | 높음 | 편집 흐름 | 첫 사건의 기본 프리셋이 기준 이미지와 같은 넓은 장면이라 실제 변화가 없는데도 `이번에 바뀐 것`으로 표시됨 | 각 사건에서 기준과 다른 첫 편집안을 기본 선택해 비교의 출발점을 분명히 함 |
| F-04 | 중간 | 콘텐츠/UI | 사건 카드의 기호가 실제 장면(벤치, 새싹 등)과 연결되지 않아 사건을 빠르게 구분하기 어려움 | 업로드 없는 CSS 미니어처로 각 사건의 핵심 대상을 시각화함 |
| F-05 | 중간 | 모바일 | 600px 이하에서 진행 단계명이 모두 숨고 숫자만 남아 현재 활동의 의미를 알기 어려움 | 작은 화면에서도 짧은 단계명을 숫자 아래에 유지함 |
| F-06 | 낮음 | 첫 화면 | 일부 데스크톱 너비에서 제목의 마지막 `요?`가 한 줄에 홀로 남음 | 제목 최대 크기와 열 너비를 조정해 문장 리듬을 안정화함 |

## 구현 원칙

- 초등학생이 조작 결과와 다음 행동을 바로 이해할 수 있는 문장을 사용합니다.
- 변화가 없는 상태를 변화로 설명하지 않습니다.
- 화면에서 확인한 사실, 화면 근거가 있는 가능한 느낌, 화면 밖 단정을 엄격히 구분합니다.
- 모바일에서도 단계명과 완료 조건을 숨기지 않습니다.
- 개인정보 보호 원칙(업로드·저장·추적 없음)은 유지합니다.

## 검증 계획

1. 정적 빌드와 기존 자동 테스트를 실행합니다.
2. 관찰 미완료 상태의 이동 잠금과 완료 후 이동을 실제 브라우저에서 확인합니다.
3. `추측 가능` 답을 `직접 확인`으로 선택했을 때 결과로 넘어가지 않는지 확인합니다.
4. 375px, 768px, 1280px 화면에서 진행 단계와 카드 미리보기를 다시 점검합니다.
5. 업데이트 내역에 이번 개선 내용을 기록하고 배포본을 확인합니다.

## 완료 기록

### 구현 결과

- F-01 완료: 관찰 단서를 체크박스로 바꾸고 `0 / 4` 완료 수와 미완료 이동 잠금을 추가했습니다.
- F-02 완료: 기대 해석 범위와 학생이 선택한 범위가 정확히 같을 때만 통과하도록 판정을 수정했습니다.
- F-03 완료: 각 사건의 두 번째 편집안을 초기값으로 사용해 기준 이미지와 실제 차이가 보이도록 했습니다.
- F-04 완료: 운동장 벤치, 복도 안내판, 새싹, 준비물, 나눔함을 나타내는 CSS 미니어처를 사건 카드에 적용했습니다.
- F-05 완료: 모바일 진행표에 `기준 관찰`, `편집 선택`, `효과와 근거`, `비교 기록` 단계명을 유지했습니다.
- F-06 완료: 데스크톱 첫 화면의 제목 크기와 열 비율을 조정해 마지막 글자가 홀로 남지 않도록 했습니다.
- 앱의 `업데이트 내역`에 v0.2.0(2026.07.17)을 추가했습니다.
