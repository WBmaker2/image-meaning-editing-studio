# 이미지 의미 편집실 학습 이미지 생성·삽입 계획

## 목적

현재 학습 장면은 `SceneIllustration`의 CSS 도형과 기호로 그려져 있습니다. 이를 이미지 생성 모델로 만든 고정 학습 이미지로 바꾸어, 학생이 더 자연스러운 장면을 관찰하면서도 기존의 자르기·크기·글·색 비교 활동은 그대로 할 수 있게 합니다.

## 현재 구조 분석

- 학습 사건은 운동장 벤치, 복도 안내판, 학교 텃밭 새싹, 준비물 안내, 물건 나눔함의 5개입니다.
- `app/components/SceneIllustration.tsx`가 모든 기준·편집 장면을 CSS로 그립니다.
- `app/styles/scenes.css`가 자르기·배치·색 변화 프리셋을 CSS 필터와 레이아웃으로 적용합니다.
- `app/data/cases.ts`의 대체 텍스트와 긴 설명이 관찰해야 할 사물과 범위를 정의합니다.
- 학생 사진 업로드, 실제 인물, 상표, 외부 사진은 사용하지 않는 프로젝트 계약을 유지합니다.

## 프롬프트 공통 기준

- 초등학교 국어·미술 수업용, 따뜻하고 단순한 편집 가능한 평면 일러스트
- 16:10 가로 장면, 주요 사물이 충분히 크게 보이는 중앙 구도
- 실제 인물·얼굴·손·상표·워터마크·읽을 수 있는 임의 글자·숫자 배제
- 과장된 사실성보다 관찰 가능한 모양·자리·색 차이를 우선
- 모델이 만든 이미지는 장면의 기준 배경으로만 사용하고, 학습용 글자·라벨·비교 캡션은 기존 HTML/CSS로 유지

## 구현 순서

1. 이미지 생성 모델로 5개 장면을 각각 생성하고 실제 결과를 확인합니다.
2. 결과 파일을 `public/learning-scenes/`에 저장합니다.
3. `SceneIllustration`을 이미지 기반으로 바꾸고 `object-position`으로 기존 자르기 프리셋을 유지합니다.
4. 안내판·표지·날짜표·이름표처럼 학습에 필요한 글자는 HTML 오버레이로 유지해 글자 정확성을 보장합니다.
5. 작은 화면에서 이미지가 잘리고 대체 텍스트가 유지되는지 테스트합니다.
6. 업데이트 내역에 이미지 생성·삽입 변경을 기록합니다.

## 완료 기준

- 5개 사건 모두 생성 이미지가 기준 화면에 보입니다.
- 기존 프리셋의 자르기·크기·색 변화와 학습 판정 테스트가 유지됩니다.
- 생성 이미지에 외부 인물·상표·임의 텍스트가 없습니다.
- `npm test`, `npm run typecheck`, `npm run lint`가 통과합니다.
